What is a rule?

A rule is a saved search with a destination — “photos that look like a mountain go into the album Mountains”. Instead of redoing the same search by hand, save it once. Preview shows what it would add without changing anything; Apply adds them. Running a rule again later only adds photos that aren't in the album yet, so it keeps albums up to date as you upload more. Rules only ever add to albums — they never move or delete anything.

Tip: set up a search on the Search tab until the results look right, then press Save as rule….

Smart albums

A smart album says what belongs in it — a description (a thing, a franchise, an action like “people dancing”), “photos like this one”, or just people — plus filters, and adds every match to its album. It only ever adds: nothing is moved or removed, a photo you take out is never put back, and every run can be undone from History. Your former rules are here too (as “best N”, not running hourly).

Clean up unnamed people

Every unnamed person, blurriest first. The score measures how much fine detail their sharpest face has at the size Immich's recognizer looks at — dark faces are not penalised. Roughly: under ~8 is usually an unrecognisable smudge, above ~20 is almost always clear. Heavily pixelated faces can still score high, so have a look before hiding. Hiding only removes someone from the People page; nothing is deleted and you can unhide any time.
